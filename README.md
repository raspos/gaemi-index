- **KRX vs NXT**: 대표지수(`GAEMI 50 PURE`)는 2021년 이후 시계열 연속성을 위해 **KRX 정규장 단독 기준**으로 산출하며, 2025년 3월 출범한 넥스트레이드(NXT) 합산 지수(`GAEMI 50 TOTAL`)와 2026 Q4 구성 종목이 **47/50개(94%) 일치**합니다.
